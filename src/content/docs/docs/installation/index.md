## 문서 상태

실제 설치 절차와 배포 파일은 미확정입니다. 아래는 문서 작성 체크리스트입니다.

## 설치 전 준비

지원 운영체제, 런타임, 권한과 네트워크 요구 사항을 제품 버전별로 기록합니다.

## 설치 및 확인

검증된 배포 경로와 설치 명령, 버전 확인 방법을 함께 제공할 예정입니다. 현재 실행 가능한 PMR 설치 명령은 제공하지 않습니다.
