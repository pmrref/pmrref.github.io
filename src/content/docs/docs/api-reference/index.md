## 참조 상태

공개 API와 SDK는 미확정입니다. 아래 표는 향후 작성 양식이며 실제 엔드포인트 목록이 아닙니다.

## API 작성 양식

| 항목 | 기록할 내용 |
| --- | --- |
| 이름 | 공개 함수 또는 엔드포인트 |
| 입력 | 타입과 필수 여부 |
| 출력 | 반환 형식과 의미 |
| 오류 | 오류 조건과 처리 방법 |
| 버전 | 도입 및 변경 버전 |
