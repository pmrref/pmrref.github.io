## 시작하기

PMR은 Programmable Message Router의 약자입니다. 먼저 제품 개념을 확인하고 설치와 설정 문서 순서로 읽으세요.

## 사전 확인

- 사용할 제품 버전
- 실행 환경과 지원 플랫폼
- 메시지 입력과 출력의 요구 사항

제품 버전과 플랫폼은 사양 확정 후 추가합니다.
